## Contributing

Create a focused branch and pull request. Install dependencies with `npm ci`
and run `npm run build` before submitting. Check changed sections at mobile and
desktop widths; for 3D changes, also verify model loading, cleanup, performance,
and fallback behavior. Do not include unrelated generated `dist/` output.
